# VICEVERSE v1.2
Independent fan-made hub for the world of Leonida. Not affiliated with Rockstar Games or Take-Two Interactive.

Static site (HTML, CSS, JavaScript). No build step, no backend, no cost.

## Run locally
    python3 -m http.server 8000      # then open http://localhost:8000

## Publish free (Cloudflare Pages + GitHub)
1. Create a public GitHub repo called `viceverse` and upload ALL files in this folder (not the zip).
2. Cloudflare Pages > Create project > Connect to Git > pick the repo.
3. Framework preset: None. Build command: empty. Output directory: `.`
4. Deploy. You get a free https://<name>.pages.dev address.
5. Android: open it in Chrome > menu > Install app. iPhone: Safari > Share > Add to Home Screen.

(Netlify Drop or GitHub Pages also work: just upload this folder.)

## Editing content
All entries live in `data.js`. After any change, bump `VERSION` in `sw.js` so installed apps pick up the update.

## Notes
- Tracker data is stored in each device's localStorage. Use Export/Import to move it.
- Map is a schematic with approximate positions, not an official map.
- Content last reviewed 15 Nov 2026 against Rockstar, Xbox Wire and press reports.

## v1.1: ads and guides
- Guides, About, Privacy, Contact and Disclaimer pages are generated by `tools/build.js`.
  Run it with your real values, then upload the changed files:

      SITE_URL=https://your-site.pages.dev CONTACT_EMAIL=you@example.com node tools/build.js

  This also rewrites sitemap.xml, robots.txt and the service worker cache list.
- Ads are OFF until you edit `config.js` (AdSense publisher ID and slot IDs). Apply to AdSense first.
- After AdSense approves you, put your line in `ads.txt` (it must be at the site root).
- Always bump `VERSION` in `sw.js` after changing any file, so installed apps update.
- See `BUSINESS_PLAN.md` for the revenue model, risks and a dated launch plan.

## v1.2: quiz and news-draft helper
- `quiz.html` is a shareable fan quiz (result card can be saved as an image).
- `tools/digest.js` + `.github/workflows/news-draft.yml`: optional Gemini-powered DRAFT helper.
  Add secret `GEMINI_API_KEY` and variable `GEMINI_MODEL` in GitHub, then run it from the Actions tab.
  Never put your API key in any site file.

## v1.3: where to host (read this before using Vercel)
- **Vercel Hobby (free) is for personal, non-commercial use only.** Third-party summaries of its terms list
  ads and monetization as not allowed on Hobby, so an AdSense site there risks suspension. Vercel Pro is paid.
  Check Vercel's current terms yourself before deciding.
- **Cloudflare Pages (free) and Netlify (free) allow commercial use**, so use one of them for a site with ads.
  Cloudflare Pages: Framework preset None, build command empty, output directory `.`
- If you still want Vercel (for example Pro, or a no-ads preview): import the GitHub repo, Framework Preset "Other",
  leave Build Command empty and Output Directory empty/`.`. `vercel.json` is already included.
- `_headers` is used by Cloudflare Pages and Netlify. Both config files make the service worker update quickly.
- Daily trivia: edit the `POOL` list in `daily.js` to add questions (first option is the correct one). Bump `VERSION` in `sw.js` after.

## v1.4: automatic daily news (open source, free)
How it works: a GitHub Action runs twice a day, reads the feeds in `tools/sources.json`, and for **official** sources
(Xbox Wire, PlayStation Blog) asks Gemini for a short own-words summary of GTA VI posts. Results go to `news-auto.json`
as "confirmed". Non-official headlines are never published automatically: they appear in a GitHub Issue for you to review.
The site reads `news-auto.json` straight from GitHub, so Netlify does not need to redeploy.

Setup (about 10 minutes):
1. Create a **public** GitHub repo and upload ALL project files, including the `.github` folder.
2. Repo Settings > Secrets and variables > Actions: add Secret `GEMINI_API_KEY`, and Variable `GEMINI_MODEL` (model name from Google AI Studio).
3. In `config.js` set `newsFeedUrl` to `https://raw.githubusercontent.com/<username>/<repo>/main/news-auto.json`, then redeploy the site once.
4. Actions tab > "Daily news" > Run workflow, to test. Check the log for "Published" or "Feed failed".
Notes: feed URLs are not guaranteed, so edit `tools/sources.json` if a feed fails. GitHub may pause scheduled runs after 60 days of no repo activity.
